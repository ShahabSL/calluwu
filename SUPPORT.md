# Support

Use GitHub Discussions or an issue for reproducible questions about the open
source SDK, contracts, WebRTC client, examples, or runtime. Include the package
version, operating system, minimal reproduction, expected behavior, and actual
behavior.

Do not include credentials, phone numbers, transcripts, audio, customer data,
or private deployment details. Report vulnerabilities privately as described
in `SECURITY.md`.

Calluwu Cloud account, billing, carrier, and hosted-service support is separate
from community support for this repository.
